# AI 팀

Claude Code 기반 AI 멀티에이전트 팀입니다.

---

## 팀 구성

| 역할 | 이름 | 주요 업무 |
|------|------|-----------|
| 👑 팀장 | 준혁 | 지시 수령, 팀원 배분, 결과 통합, 보고 |
| 🏗 아키텍트 | 민준 | 시스템 설계, 기술 스택 선정 |
| 🔍 리서쳐 | 지훈 | 기술 조사, 자료 수집 |
| 🎨 UI/UX | 수아 | 화면 설계, 디자인 |
| 💻 개발자 | 서연 | 코드 작성, 기능 구현 |
| ✅ QA | 태양 | 코드 리뷰, 테스트 |

## 사용 방법

**준혁(팀장) pane에 입력하면 자동으로 팀원에게 위임됩니다.**

```
사용자  >  할 일 내용을 여기에 입력
```

```
┌─ 👑 준혁 (팀장) ──────────────────────────────────────┐
│  알겠습니다. [팀원]에게 요청하겠습니다.               │
└────────────────────────────────────────────────────────┘
               ↓ 자동 위임 (Enter 불필요)
┌─ [팀원] ───────────────────────────────────────────────┐
│  작업 처리 중...                                       │
│  ✅ 준혁, [팀원] 완료: [결과 요약]                    │
└────────────────────────────────────────────────────────┘
               ↓ 자동 보고
┌─ 👑 준혁 (팀장) ──────────────────────────────────────┐
│  ✅ [팀원] 완료: [결과 요약]                          │
│  저장 위치: ~/forever-ai/workspace/                     │
└────────────────────────────────────────────────────────┘
```

## tmux 단축키

| 단축키 | 기능 |
|--------|------|
| `Ctrl+B` 후 화살표 | pane 이동 |
| `Ctrl+B` 후 `z` | 현재 pane 전체화면/복원 |
| `Ctrl+B` 후 `d` | 세션 분리 (팀은 계속 실행) |
| `tmux attach -t forever` | 분리된 세션 재연결 |

## 문제 해결

**AI 팀이 응답하지 않는 경우:**
```bash
bash ~/forever-ai/start.sh
```

**Google Drive/Gmail 연동 오류:**
```bash
bash ~/forever-ai/setup-google.sh
```
